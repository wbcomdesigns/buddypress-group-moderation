# Installation

**Included in Free**

1. Download the plugin from wbcomdesigns.com.
2. In WordPress, go to **Plugins > Add New > Upload Plugin**, choose the zip file and click **Install Now**.
3. Click **Activate**. You are taken to **WB Plugins > Group Moderation**.

The plugin is free. Updates come from Wbcom Designs on a built-in licence key, so there is no licence key to enter.

## If the Groups component is off

The plugin stays active and shows a notice: "BuddyPress Group Moderation requires the Groups Component to be enabled in the BuddyPress settings." Turn Groups on under **Settings > BuddyPress > Components** and moderation starts working with your saved settings.

## Default settings

| Setting | Default |
|---|---|
| Auto-approve admin groups | On |
| Send email notifications | On |
| Delete settings on uninstall | Off |
